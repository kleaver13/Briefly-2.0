# Briefly Homepage

Static landing page based on the approved Briefly homepage design.

## Files

- `index.html` — page structure and editable copy
- `styles.css` — layout, typography, spacing, buttons, responsive behavior
- `script.js` — placeholder for future interactions
- `assets/briefly-hero-visual.png` — exact visual crop from the approved design
- `assets/reference-homepage.png` — full reference image

## Deploy on GitHub Pages

1. Create or open your GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Set **Source** to **Deploy from a branch**.
6. Select `main` and `/ (root)`.

## Vercel

Import the repository into Vercel. This is a static site and requires no build command.

## Important

The lower Briefly product visual is kept as a PNG so it matches the approved artwork exactly.
The navigation, headline, supporting copy, CTAs, and platform line are real HTML/CSS so they remain crisp and editable.
